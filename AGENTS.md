# AGENTS.md: Speaches Cloudron package working contract

The settled-decisions record for packaging **Speaches** (`speaches`, MIT) as
a Cloudron community app. Read this before changing anything. Do not
relitigate these decisions without a concrete reason found on a running
box. **The box is the authority, not the docs.**

## What this package is

Speaches is a self-hosted, OpenAI-compatible speech to text and text to
speech server (faster-whisper, Kokoro, Piper), packaged here from
upstream's CPU image build at version 0.9.0-rc.3.

Topology, one row per process, all logging to stdout:

| Process | Role | Port (localhost unless noted) |
|---|---|---|
| nginx | Ingress: static `/healthz`, request body size limit, streaming and websocket proxying to the app | 8000 (external, manifest `httpPort`) |
| speaches (uvicorn/FastAPI) | The application: OpenAI-compatible speech API plus the Gradio playground UI | 127.0.0.1:8001 |

State: no database, queue, or cache addon. The `localstorage` addon backs
up `/app/data` (API key, package config). `/var/lib/speaches` is a
`persistentDirs` entry holding the Hugging Face model cache, deliberately
excluded from backup (ADR 0004).

## Golden rules

1. **Conformance to the Cloudron contract first.** Adapt the application's
   runtime environment only. Never patch the application itself.
2. **Pin everything by digest**: the base image, every upstream image,
   every bundled service. Exactly one build argument per upstream version,
   mirrored in the manifest as `upstreamVersion`.
3. **Persisted state only in `/app/data`.** Re-assert ownership and mode
   on **every** boot, because a restore drifts them.
4. **Fail loud.** Never silently regenerate a data-loss-critical secret,
   and never clobber operator configuration.
5. **Code and docs ship together.** ADRs in `docs/decisions/`. The
   verified-versus-assumed log in `docs/PACKAGING-NOTES.md`, newest first.
   Box-specific working notes stay in gitignored `phase-notes/`.
6. **`CMD`, never `ENTRYPOINT`**, because `ENTRYPOINT` breaks Cloudron
   debug mode. Maintain `.dockerignore` as carefully as `.gitignore`.
7. **Open source only.** State which upstream build flags or directories
   are excluded, and never enable licence-gated features.
8. **Anonymise before every push.** No box or mirror hostnames, no real
   emails, no tokens, no internal URLs in any tracked file. `example.com`
   is the placeholder in public docs. `test/secret-scan.sh` is the release
   gate.
9. **Git hygiene.** No AI co-authorship and no tool-attribution trailers.
   Commit as the maintainer identity, set **repo-local**, because the
   machine global is a placeholder.

## Locked decisions (Phase 0, operator-confirmed 2026-07-30)

- **Manifest id:** `io.github.orcvole.speaches`. The repository's
  `-cloudron` suffix does not enter the id. `author` and `packagerName`
  are both `OrcVole`. `packagerUrl` is
  `https://github.com/OrcVole/speaches-cloudron`. `contactEmail` is
  `Most+github@OrcadianVole.com`.
- **Registry:** `ghcr.io/orcvole/speaches-cloudron`, never
  `ghcr.io/orcvole/speaches` (that name is a different, unrelated image
  namespace). Pushed public so the box pulls without credentials. Exact
  image tag scheme is not yet decided; finalised at the phase 3 build.
  Deployment always references the image by digest regardless of tag,
  per standing doctrine (never float a tag).
- **Repos:** GitHub `OrcVole/speaches-cloudron` is canonical. A private
  mirror also exists; its URL is maintainer-local and deliberately not
  recorded in tracked files.
- **memoryLimit:** the manifest currently carries a placeholder value of
  `4294967296` (4 GiB). This is **not a measured number**. It must be
  replaced with a value derived from a real warmup-and-inference-peak
  measurement against the default preloaded model set, on the actual
  target host, before this package ships (gate-ladder memory
  methodology; see `docs/DEBUGGING.md`). Do not treat the placeholder as
  a sizing decision.
- **Health:** `healthCheckPath = /healthz`, served as a static 200
  directly by nginx rather than proxied to the app. This keeps the
  restart-loop signal independent of upstream's own auth-gating changes
  to `/health` across versions (ADR 0003).
- **Auth topology:** no auth addon of any kind. A single API key,
  generated by the package on first boot, authenticates both the API and
  (pasted once per browser) the playground UI. `optionalSso: true`. No
  `proxyAuth`, and none is planned: it is a one-way manifest door and the
  UI shell is already inert without the key (ADR 0005, option A',
  operator-accepted).

## ADR summary

One line per decision; read the full ADR in `docs/decisions/` before
acting on any of these.

- **0001, CPU-only inference:** package the upstream CPU variant only;
  state performance honestly once measured; carry no dormant CUDA weight.
- **0002, build shape:** two-stage build, both stages `cloudron/base`
  pinned by digest; shape 1 (fresh venv, clone plus `uv sync --frozen`)
  attempted first, shape 2 (venv copied from the upstream image) is the
  fallback; resolved with a build gate and a runtime smoke test at phase
  3, not yet run.
- **0003, ingress and nginx:** a thin nginx front end, kept for request
  body size limits, streaming buffering behaviour, websocket support, and
  a stable static `/healthz`, not for the vLLM-style slow-boot reason
  (Speaches binds its port quickly with an empty cache).
- **0004, model storage:** `/var/lib/speaches` on `persistentDirs` holds
  the Hugging Face cache; excluded from backup by design; re-download is
  the restore. The API key and package config stay on the backed-up
  `/app/data`.
- **0005, auth topology:** ACCEPTED by the operator. Native generated API
  key, playground UI enabled, no `proxyAuth`, `optionalSso: true` (option
  A'). Sibling consumability (OpenWebUI, LibreChat, the gateway) is a
  first-class requirement of this shape.
- **0006, environment namespace:** package-defined settings use the
  `SPEECH_` prefix; genuine upstream settings pass through under their
  real, unprefixed names; every forced upstream variable is set
  explicitly in `start.sh` with a comment naming the field it drives.

## Secrets

First-run only, idempotent, under `/app/data`, mode 0600, re-asserted on
every boot.

| Secret | Shape | Criticality | Notes |
|---|---|---|---|
| API key (`keys.env`, at `/app/data/.secrets/keys.env`) | `openssl rand -hex 32`, written as `API_KEY=<value>` in a one-line env file, `0600` inside a `0700` directory | seed-once, auth-tier (not encryption-tier: there is no database, so a reseed only breaks integrators until they re-copy the key, per doctrine digest 9.4) | Generated on first boot only, never regenerated; ownership and mode re-asserted on every boot outside the first-run branch; exported as `API_KEY`, never passed on argv; must be proven byte-identical (sha256) across a real update and restore once `start.sh` exists (phase 4 onward). |

## Environment mapping

Translate on every boot, once `start.sh` exists (phase 4). Verified
against upstream source reading; empirical confirmation on a running
image is still open (ADR 0006 executor hooks).

| Application variable | Source or value | Notes |
|---|---|---|
| `SPEECH_STT_MODEL` | package setting, operator-overridable | default speech to text model id; feeds `PRELOAD_MODELS` |
| `SPEECH_TTS_MODEL` | package setting, operator-overridable | default text to speech model id; feeds `PRELOAD_MODELS` |
| `SPEECH_TTS_VOICE` | package setting, operator-overridable | default voice for the preloaded text to speech model |
| `SPEECH_EXTRA_PRELOAD` | package setting, operator-overridable | comma-separated list appended to `PRELOAD_MODELS` |
| `SPEECH_UI` | package setting, operator-overridable, default on | maps to upstream `ENABLE_UI` |
| `API_KEY` | forced, from `keys.env` | upstream's own auth field; note `SPEACHES_API_KEY` is a different, unprefixed-only-in-appearance name and is silently ignored upstream |
| `UVICORN_HOST` | forced to `127.0.0.1` | upstream pydantic field alias for bind host; plain `HOST` does nothing |
| `UVICORN_PORT` | forced to `8001` | upstream pydantic field alias for bind port; plain `PORT` does nothing |
| `PRELOAD_MODELS` | forced, JSON list assembled from the `SPEECH_*` settings above | upstream field; downloads occur before the port binds and the process exits if any download fails |
| `WHISPER__*` | forced only where the package must (double-underscore nested fields) | upstream nested pydantic configuration |
| `LOG_LEVEL` | forced to `info` | the upstream debug default dumps the entire configuration to logs on every boot |
| `HF_TOKEN` | passthrough, untouched | operator-set only, for gated Hugging Face models; never referenced by package logic |
| `HF_HOME` | forced to `/var/lib/speaches/hf` | redirects the Hugging Face cache onto `persistentDirs` |
| `XDG_CACHE_HOME` | forced to `/app/data/cache` | redirects other caches off the read-only filesystem |
| `HF_HUB_DISABLE_TELEMETRY`, `DO_NOT_TRACK`, `GRADIO_ANALYTICS_ENABLED`, `PYANNOTE_METRICS_ENABLED` | forced | telemetry opt-outs already present in the upstream image, carried forward |

## Backup and restore

`/app/data` (API key, package configuration) is backed up normally by the
`localstorage` addon. `/var/lib/speaches` (`persistentDirs`, the Hugging
Face model cache) survives restart, update, and in-place restore, but is
excluded from the filesystem backup and starts empty on a clone or a
fresh install; re-download is the deliberate restore mechanism (ADR
0004). No `backupCommand` or `restoreCommand` is declared.

## Future compatibility

The single bump point for a version upgrade is the upstream version build
argument, mirrored into the manifest's `upstreamVersion` field. Upstream
is currently in a maintenance stall (see `docs/PACKAGING-NOTES.md`); the
planned bump to a 0.9.0 stable release may not land, in which case the
first update exercises the versions-channel update mechanism against a
cosmetic 0.1.1 of this package instead. A CUDA image variant remains
structurally possible later (ADR 0001) if the platform ever offers GPU
passthrough, without needing to change the environment-driven
configuration or the ingress arrangement. Deliberately out of scope for
v1, with its reasoning recorded rather than silently dropped: a
`proxyAuth`-fronted SSO wall (ADR 0005, option C, rejected as the
default; revisit only if upstream ever makes the playground UI key-free).

  decided; only the repository name is a hard constant.
